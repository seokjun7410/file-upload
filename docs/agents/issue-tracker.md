# Issue tracker: Local Markdown

이 저장소의 스프린트 PRD는 `docs/sprints/` 아래의 Markdown 파일로, 구현 이슈는 `.scratch/` 아래의 Markdown 파일로 관리한다.

## 규칙

- 스프린트 PRD는 `docs/sprints/<sprint-slug>/<sprint-slug>-prd.md`에 둔다.
- 기능 하나당 `.scratch/<feature-slug>/` 디렉터리를 사용한다.
- 구현 이슈는 필요할 때 `.scratch/<feature-slug>/issues/<NN>-<slug>.md`로 만든다.
- triage 상태는 파일 상단의 `Status:`에 기록한다.
- 논의와 변경 이력은 파일 하단 `## Comments`에 누적한다.
